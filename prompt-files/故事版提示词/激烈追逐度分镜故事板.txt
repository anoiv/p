激烈追逐度分镜故事板

[任务]
请帮我生成一张未来都市街头，两名骑手驾驶高速机车激烈追逐交火的手绘风格分镜稿

[画面风格]
1. 画面布局：该手绘风格分镜稿使用4X3的布局模式，每行4张，共3行
2. 画风线条：铅笔手绘草稿速写风，少量彩色手绘线条
3. 人物设定：重点突出高速机动与火力压制，表现机车漂移、穿越车流、空中飞越等大动态动作

[要求]
1. 用快速、有力的铅笔线条勾勒，不追求精细光影和色彩，重点突出角色动作张力与镜头节奏，能高效传递高速追击战的紧张感
2. 每个镜头都标注镜头类型（如超低角度甩拍、航拍跟随、肩扛近景）、表演提示、音效说明
3. 画面中需用不同颜色的箭头来标注引导线
- 红色：机位运动/构图
- 蓝色：角色动作轨迹
- 绿色：互动关系/攻击轨迹
- 橙色：效果/冲击力
- 紫色：音效/标注引导
4. 以下12个镜头完整串联起一场都市街头机车激烈追逐的完整桥段，通过镜头切换和动作衔接构建出流畅的飙车动作逻辑

[分镜镜头详情]（此处粘贴具体内容）
P01 / 航拍俯冲广角：城市高架桥匝道，两辆重机车从高处极限压弯俯冲而下，冲入底部车流。引擎爆裂的轰鸣声，轮胎碾过路面的摩擦声
P02 / 超低角度侧拍：后车紧逼前车，距离不足一米，后车骑手压低重心蓄势待发。风声呼啸，皮衣在风中猎猎作响
P03 / 肩扛跟拍：后车骑手单手脱把，从腰间快速拔出手枪，准备瞄准。枪械金属摩擦声，子弹上膛的清脆咔嚓声
P04 / 极低角度正后方：前车骑手从后视镜察觉危险，猛捏前刹、死拧油门，机车车头高高翘起，险险避开子弹。震耳欲聋的枪声，轮胎剧烈摩擦地面的嘶叫声
P05 / 中景推镜：前车借路边厢式货车作掩体，侧身从背后拔枪回击。清脆的回击枪声，子弹击中货车金属厢体的叮当声
P06 / 广角动感平拍：两车钻入高架桥底，剧烈明暗交替的光影划过骑手全身。引擎声在桥洞中产生强烈回响
P07 / 手持剧烈晃动：后车为躲避子弹，猛向右打方向，冲出路基，驶入废弃铁轨旁的石子路。后轮打滑声，碎石被弹飞的噼啪声
P08 / 航拍跟随：前车紧随其后冲入铁轨，两车在乱石与废弃轨道上进行极限颠簸操控。避震器剧烈压缩的嘎吱声
P09 / 地面超广角：铁轨尽头横亘一条运河，前方是死路，但前车没有丝毫减速。引擎的极限运转声
P10 / 慢动作特写：前车骑手找准角度，机车冲上一块废弃混凝土斜坡，整个车身凌空腾起。引擎拉满转速的尖锐咆哮声
P11 / 航拍侧转：机车在空中华丽飞跃运河，精准落在对岸硬化路面。沉重落地声，前避震极限压缩的沉闷声
P12 / 航拍拉远全景：后车在运河对岸猛刹停下，轮胎留下一道长长黑印，只能目送前车尾灯消失在夜色深处。逐渐弱化的引擎回火声，夜风吹拂的沙沙声
